# Universal Copy Privacy Policy

Last updated: 15 May 2026

Universal Copy is a browser extension. Universal Copy restores normal browser copy controls and provides local cleanup tools for text, URLs, snippets, and copied-item history.

## Data Collection

Universal Copy stores settings, snippets, copied-item history, domain unlock state, and usage statistics locally in the browser. It does not sell data, share data with third parties, or include advertising analytics.

## Page Access

Universal Copy runs on pages so it can restore right-click, text selection, copy shortcuts, drag selection, and touch selection where a site has blocked normal browser controls.

## Network Requests

Universal Copy does not transmit page content, clipboard contents, snippets, browsing history, or settings to a remote server.

## User Controls

Users can manage the extension through the browser extension popup and settings page. Users can disable automatic unlock, hide the floating toolbar, lock a page again, clear copied-item history, delete snippets, and reset settings to defaults.

## Contact

For support, use the support URL or email listed on the Chrome Web Store page for Universal Copy.
